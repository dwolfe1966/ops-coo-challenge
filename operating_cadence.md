# Operating Cadence

## Daily — 15-minute exception review
Only red items, overdue yellow items, and system incidents.
- What is blocked?
- What aged past SLA?
- What external action failed?
- Which item lacks an owner?
No status theater; green work stays out of the meeting.

## Weekly — 45-minute operating review
Single scorecard:
1. Revenue / customer-risk outcomes.
2. Queue health: age, ownership, SLA breaches.
3. Automation quality: accepted, edited, rejected, false positives, incidents.
4. Top 3 decisions requiring cross-functional tradeoff.
5. Experiments and forecast-vs-actual.

Every item ends with **owner + next action + date + success condition**.

## Monthly — 60-minute automation portfolio audit
Each workflow gets one of: KEEP / IMPROVE / MERGE / KILL.
Review:
- attributable outcome
- review burden
- failure cost
- signal quality
- automation autonomy level

## Executive sponsor
Executive sponsor sees:
- red decisions
- policy-threshold changes
- material capital/people tradeoffs
- recurring failure patterns

The sponsor should not approve routine yellow/green output.
