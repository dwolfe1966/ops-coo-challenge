# Automation Portfolio Audit

Framework: **Outcome value × signal quality × actionability × ownership ÷ failure cost / review burden**

| Workflow | Decision | Reason |
|---|---|---|
| Search/content opportunity scan | **IMPROVE** | Keep only for active clients; rank by expected impact; cap recommendations; require owner. Q-14 proves stale customer state can invalidate the output. |
| Prospect sourcing & enrichment | **IMPROVE / temporarily gate auto-send** | Valuable, but Q-08 and Q-17 show identity-quality and dedupe failures. Separate sourcing from sending until quality clears threshold. |
| Content repurposing | **IMPROVE** | Keep drafting leverage, but require provenance checks for client metrics and clear approval ownership. Q-16 is a red-line failure. |
| Deal/customer revival scan | **IMPROVE** | Commercially useful if every item has a named owner, next action, and completion evidence. Q-13 shows dashboard status is not proof. |
| Competitive monitoring | **MERGE** | Merge price/product alerts into one scored digest; suppress duplicates/noise; escalate only when there is an explicit client/revenue implication. |
| Customer-risk detector | **KEEP + FIX** | Highest potential value, but dedupe and closed-loop ownership are mandatory. Q-01/Q-09 show duplicate-generation; Q-15 shows true high-risk use. |
| Editorial planning | **IMPROVE / shrink** | Keep only if every topic maps to a client/company priority. Q-10 shows output without strategic linkage. |
| Candidate/partner follow-up | **IMPROVE** | Keep reminders/drafts, but require relationship-state validation before send. Q-18 demonstrates contextual conflict risk. |

## Portfolio kill rule
A workflow is killed or paused when it has **low attributable outcome value**, **persistent low signal quality**, or **review/cleanup cost greater than the value it creates**.

## Monthly audit fields
- items generated
- % acted
- median time-to-owner
- median time-to-action
- stale/duplicate rate
- false-positive rate
- auto-execution error rate
- human edit/reject rate
- attributable revenue/risk avoided
- review minutes per useful action
